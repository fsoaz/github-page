# 🖥️ Francisco Soares — Terminal Portfolio

A sleek, terminal-inspired personal portfolio built with pure HTML, CSS, and a touch of JavaScript. Designed to mimic a Unix-like CLI experience while showcasing backend engineering skills and projects.

---

## ✨ Features

- 🧠 **Terminal UI/UX** — Simulates a real command-line interface
- 🎨 **Modern Dark Theme** — Carefully crafted color palette with gradients
- ⚡ **Lightweight** — No frameworks, just pure HTML/CSS/JS
- 📱 **Responsive Design** — Works across desktop and mobile
- ⌨️ **Command-Based Sections**:
  - `whoami` → About section
  - `ls --tree skills/` → Skills overview
  - `cat projects.json` → Projects list
  - `ssh-keyscan` → Social links
  - `mail --to` → Contact form

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Custom properties, animations)
- **Vanilla JavaScript**
- **JetBrains Mono Font**
